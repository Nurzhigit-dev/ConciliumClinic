# Consilium International Clinic

Сайт международной клиники экспертной медицины — Уральск, мкр. Астана, 12.

**Живая версия:** https://nurzhigit-dev.github.io/ConciliumClinic/

---

## Что внутри

```
index.html            вся разметка страницы
assets/css/styles.css оформление
assets/js/main.js     мозаичный герой, статус работы, меню, появление блоков
assets/img/           логотип, фотографии клиники и врачей, favicon
source/               исходники: оригинал логотипа и постеры врачей до кадрирования
```

## Как посмотреть локально

```bash
python -m http.server 5173
```

Затем открыть http://localhost:5173


## Дизайн


| Роль | Шрифт | Где используется |
|---|---|---|
| Заголовки | Geologica | Экран приветствия, заголовки разделов, имена врачей |
| Текст | Onest | Абзацы, списки услуг |
| Данные | JetBrains Mono | Часы работы, телефоны, подписи разделов |
