# Consilium International Clinic

Сайт международной клиники экспертной медицины — Уральск, мкр. Астана, 12.

**Живая версия:** https://nurzhigit-dev.github.io/ConciliumClinic/

---

## Что внутри

Статический сайт без сборки: открывается двойным кликом по `index.html`, публикуется
на GitHub Pages как есть.

```
index.html            вся разметка страницы
assets/css/styles.css оформление
assets/js/main.js     мозаичный герой, статус работы, меню, появление блоков
assets/img/           логотип, фотографии клиники и врачей, favicon
source/               исходники: оригинал логотипа и постеры врачей до кадрирования
```

## Как посмотреть локально

```bash
python -m http.server 5173
```

Затем открыть http://localhost:5173

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → ветка `main`, папка `/ (root)`.
Через минуту сайт будет доступен по адресу выше.

## Дизайн

Палитра снята пипеткой с логотипа клиники: тёмно-синий `#0B3054` и бирюзовый `#0E9184`.

| Роль | Шрифт | Где используется |
|---|---|---|
| Заголовки | Geologica | Экран приветствия, заголовки разделов, имена врачей |
| Текст | Onest | Абзацы, списки услуг |
| Данные | JetBrains Mono | Часы работы, телефоны, подписи разделов |

Фирменный элемент — мозаичный шар из логотипа, собранный заново на `<canvas>`:
сетка квадратов медленно вращается, а квадраты на правом краю отрываются и
рассыпаются бирюзой, повторяя распад в исходном знаке.

## Что страница делает сама

- **Статус работы.** Часы клиники (08:00–20:00) сверяются с текущим временем в
  Казахстане (UTC+5), а не в часовом поясе посетителя. В шапке — «Открыто» или
  «Закрыто», в разделе «Как нас найти» — шкала суток с отметкой «сейчас» и
  подсчётом времени до открытия или закрытия.
- **Нижняя панель на телефоне.** «Позвонить» и «WhatsApp» всегда под рукой.
- **Бережное отношение к настройкам.** При включённом «уменьшении движения»
  анимации отключаются, а мозаика замирает на одном кадре.

## Как обновить содержимое

Всё, что видно на сайте, лежит в `index.html` обычным текстом — телефоны, адрес,
списки услуг и врачей можно править прямо там.

**Часы работы** заданы в двух местах, менять нужно оба:

- `assets/js/main.js` — константы `OPEN` и `SHUT` в блоке `hours()`
- `index.html` — текст «Ежедневно 08:00 — 20:00» и блок `openingHoursSpecification`

**Добавить врача:** скопировать блок `<article class="doc">` в разделе `#doctors`
и положить портрет в `assets/img/` (вертикальный кадр, лицо в верхней трети).

**Заменить фотографии:** положить файл в `assets/img/` под тем же именем. Если
пропорции другие — поправить `width` и `height` у тега `<img>`, иначе страница
дёрнется при загрузке.

## Что стоит уточнить

- Город и область (`Уральск, Западно-Казахстанская область`) взяты из карточки
  2ГИС — проверьте, как клиника указывает адрес официально.
- В списки услуг добавлены **детский невропатолог** и **ортопед-имплантолог** —
  специальности врачей с карточек. Уберите, если приём не ведётся.
- Расписание отдельных специалистов на сайте не указано: страница отправляет
  уточнять его на ресепшн.
